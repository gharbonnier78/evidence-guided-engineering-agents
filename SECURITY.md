# Security and responsible disclosure

This repository is public and must contain only generic architecture, synthetic examples, and public references.

## Never commit

- confidential or pre-filing invention details;
- customer, employee, citizen, or other personal data;
- private chat, email, meeting, or source-control content;
- credentials, tokens, internal URLs, infrastructure addresses, or secrets;
- contract-protected documents or third-party material without redistribution rights;
- security findings that could expose a real system.

## Design rule

Connectors and agent prompts described here are specifications only. A real deployment must preserve source permissions, purpose limitation, minimization, retention controls, audit logs, and an explicit human approval gate before external transmission.

## Reporting

For a suspected vulnerability, do not open a public issue containing sensitive details. Contact the repository owner through a private channel.
